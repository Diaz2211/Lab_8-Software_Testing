# BÁO CÁO KIỂM THỬ HIỆU NĂNG VỚI APACHE JMETER

## 1. Giới thiệu về Apache JMeter
Apache JMeter là công cụ mã nguồn mở dựa trên Java được sử dụng để kiểm thử hiệu năng (Performance Testing) và kiểm thử chịu tải (Load Testing) các ứng dụng Web và API. JMeter cho phép giả lập nhiều người dùng đồng thời (Virtual Users) để đo lường thời gian phản hồi (Response Time), sức xử lý (Throughput) và tỷ lệ lỗi của hệ thống.
